# ステップ4に回す課題

最小の遊べる版（MVP）のレビューで見つかり、完成版に向けて直すもの。

- 予算の追加（addBudget）がほぼ役に立たない。上申の回数を使うのに「使ってよい予算」が増えないため。予算が足りないときだけ出す、または一部を承認済み予算に加える
- 予算超過の「現実ではこういうこと」メモ（overBudget）が出る場面がなくなった
- 「ふつう」の働き方でも疲れが回復せず、ずっと「ふつう」でも燃え尽きることがある。自然回復を少し入れる
- 遊び方の説明に「2ターンに1回はレビュー」のようなヒントを入れる（レビューの頻度で結果が大きく変わる）
- 延長（再計画）すると納期の評価が ◎ にならないことを結果画面で説明する
- 締切の2ターン前以降は外注の追加を出さない（立ち上がりに2ターンかかるため意味がない）
- 終盤のイベントが「大きなバグ」に偏っている
- 外注の単価が1ターンの週数に関係なく同じ
