# tabane（束ね）

開発プロジェクトの「1チームのチームリーダー」として、構想検討からリリースまでを進めるブラウザゲームです。
新しく配属された人や開発に興味がある人が、「組織の開発」を知るきっかけになることを目指しています。

- 遊ぶ環境: ブラウザ（Chrome）
- 1プレイ: 30分くらい

設計の詳細は [docs/design.md](docs/design.md) を見てください。

## 開発

Node.js 22 以上が必要です。

```sh
npm install
npm run dev        # 開発サーバ（http://localhost:5173）
npm test           # テスト
npm run build      # 本番用ビルド（dist/）
```

このリポジトリは公開されています。API キーやパスワードなどの秘密情報はコミットしないでください（`.env` は `.gitignore` で除外しています）。
